# Imagens Institucionais da Aplicação

Este diretório está reservado para as imagens finais do projeto:
- `logo.svg` / `logo.png`: Logotipo exibido no canto superior esquerdo da barra de navegação.
- `brasao.svg` / `brasao.png`: Brasão ou insígnia institucional exibido no cabeçalho.
- `favicon.ico`: Ícone da aba do navegador.

Enquanto as imagens oficiais não forem adicionadas, o `HeaderComponent` renderiza ícones vetoriais como placeholders visuais sem quebrar o layout.
